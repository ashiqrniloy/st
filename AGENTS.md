# Agent Code Quality Guidelines

- During planning and implementation, first define acceptance criteria from the user requirement, then define a test plan for validating those criteria, implement against the criteria, and write/update validation tests after implementation.
- Validate that tests prove the acceptance criteria, not merely implementation details.
- Prefer the simplest implementation that satisfies the acceptance criteria without weakening architecture or correctness.
- Always look for a more elegant way to implement a change before finalizing it.
